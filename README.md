# RPA GitHub

Automação Web com C# para listar repositórios no GitHub

---

## Estrutura do Projeto

O código recebe duas strings, a primeira para guardar o login e a segunda para guardar a senha. Para que não 
haja vazamento de dados, eu crio uma função para ocultar os caracteres da senha. Após, o navegador é inicializado 
e direcionado para o site do GitHub, onde o login e a senha são solicitados.Todo o processo de navegação pela Web 
é feita de forma automática, com excessão da autenticação de 2 fatores que é realizada através do SMS. 

---

## O que é uma RPA❓

RPA (do inglês, Robotic Process Automation) refere-se à tecnologia que utiliza softwares robôs (bots) para 
automatizar tarefas repetitivas, baseadas em regras e de alto volume que, tipicamente, seriam realizadas por humanos.
